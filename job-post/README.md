# 채용공고 편집기 (job-post)

사람인 채용공고 상세 이미지를 웹에서 고치고 PNG(3배, 2580px 폭)로 받는 도구입니다.

## 폴더 구성
- `index.html` : 편집기 페이지
- `shim.js` : 저장 기능 (공고 데이터를 읽고 브라우저에 저장)
- `postings.json` : 공유용 공고 데이터 (모든 사람이 처음 열 때 이 내용을 불러옵니다)
- `fonts/`, `img/` : 폰트와 상단 배경·로고 (꼭 같이 올려야 합니다)

## 올리는 방법
저장소 루트에 `job-post/` 폴더째로 올리면 `https://manual-tool-azure.vercel.app/job-post/` 에서 열립니다.

## 데이터 저장 방식
- 편집기에서 [저장]한 내용은 **그 사람의 브라우저**에만 저장됩니다.
- 모두에게 반영하려면 왼쪽 아래 [데이터 내보내기]로 받은 `postings.json`을 이 폴더의 파일과 바꿔 커밋하세요.
- 저장소의 `postings.json`이 더 최신인 공고는 다음에 열 때 자동으로 반영됩니다.

관리자 비밀번호: 페이지 코드 안의 `GATE_HASH`(SHA-256)로 확인합니다. 바꾸려면 새 비밀번호의 SHA-256 값으로 교체하세요.
